# Report

One Markdown document per research run. The document is the deliverable.

## Shape

| Section | Content |
|---|---|
| `# <Question>` | The question as fixed for this run |
| `## Answer` | The short answer, every sentence sourced |
| `## Findings` | One finding per line, each cited |
| `## Sources` | Repo + web sources, deduplicated |
| `## Open questions` | What the run could not resolve, plus unsourced claims moved here |

## Rules

- Write in the caller's repo language; keep paths, URLs, and skill names as-is.
- Update the document in place on re-run; do not fork versions.
- No answer without a source; a claim with no source → delete the claim or move it to Open questions.
- Do not implement findings. Ticket work is `engineering-process`; this skill delivers the document only.
